# Backend

This directory contains the backend server for the application.

## Setup

1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm start
    ```

## Environment Variables

This backend uses environment variables for configuration. Please refer to the `.env.example` file in the project root for required variables.
